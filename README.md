# 🧮 Математический калькулятор на Python

Консольный математический калькулятор, написанный на Python. Проект позволяет вычислять математические выражения с использованием арифметических операций, математических констант и встроенных функций.

## 📌 Возможности

- **Арифметические операции:** сложение (`+`), вычитание (`-`), умножение (`*`) и деление (`/`).
- **Возведение в степень:** оператор `**`.
- **Побитовое исключающее ИЛИ (XOR):** оператор `^` для целочисленных значений.
- **Математические функции:**
  - `sqrt(x)` — квадратный корень числа.
  - `abs(x)` — абсолютное значение числа.
  - `sin(x)` — синус угла в радианах.
  - `cos(x)` — косинус угла в радианах.
- **Математические константы:**
  - `pi` — число π.
  - `e` — число Эйлера.
- **Обработка некоторых ошибок:** предусмотрены сообщения о делении на ноль, неизвестных символах и некорректных выражениях.
- **Вычисление выражений со скобками** и поддержка унарных знаков `+` и `-`.

## 🛠️ Требования

- Python версии 3.6 или новее.
- Стандартная библиотека Python (`math`).

Устанавливать дополнительные зависимости не требуется.

## 💻 Примеры использования

После запуска программа предложит ввести математическое выражение.

```text
Введите выражение: 2 + 3 * 4
Результат 2 + 3 * 4: 14.0

Введите выражение: sqrt(25)
Результат sqrt(25): 5.0

Введите выражение: sin(pi / 2)
Результат sin(pi / 2): 1.0

Введите выражение: cos(0)
Результат cos(0): 1.0

Введите выражение: 2 ** 3
Результат 2 ** 3: 8.0
```

Чтобы завершить работу программы, оставьте строку ввода пустой и нажмите Enter.

## 📖 Поддерживаемый синтаксис

| Операция | Пример | Описание |
|---|---|---|
| Сложение | `5 + 3` | Складывает числа |
| Вычитание | `5 - 3` | Вычитает числа |
| Умножение | `5 * 3` | Умножает числа |
| Деление | `6 / 2` | Делит числа |
| Степень | `2 ** 3` | Возводит в степень |
| XOR | `5 ^ 3` | Побитовая операция XOR |
| Скобки | `(2 + 3) * 4` | Изменяет порядок вычислений |
| Квадратный корень | `sqrt(16)` | Вычисляет корень |
| Модуль | `abs(-5)` | Возвращает абсолютное значение |
| Синус | `sin(pi / 2)` | Вычисляет синус |
| Косинус | `cos(pi)` | Вычисляет косинус |

**Важно:** оператор `^` используется для побитового XOR, а не для возведения в степень. Для возведения в степень используйте `**`.

## ⚙️ Принцип работы

Программа разбирает введённое выражение на токены, а затем вычисляет его с помощью набора функций разбора:

- `parse_atom()` — обрабатывает числа, константы, скобки и вызовы функций.
- `parse_power()` — вычисляет возведение в степень.
- `parse_unary()` — обрабатывает унарные знаки.
- `parse_product()` — выполняет умножение и деление.
- `parse_sum()` — выполняет сложение и вычитание.
- `parse_xor()` — обрабатывает побитовую операцию XOR.

Для вычисления синуса и косинуса используются функции `sin_t()` и `cos_t()`, реализованные через ряд Тейлора и заданное количество членов ряда.

## ⚠️ Ограничения

- Поддерживаются только реализованные в программе операции и функции.
- Тригонометрические функции принимают аргументы в радианах.
- Выражения с некорректным синтаксисом могут приводить к ошибкам.
- Функция `sqrt()` не предназначена для вычисления квадратного корня из отрицательного числа в действительных числах.
- Оператор XOR применяется к целочисленным значениям.
- На данный момент проект не содержит графического интерфейса и работает в командной строке.
